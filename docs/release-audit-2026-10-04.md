# Проверка перед публикацией — 4 октября 2026

## Исправления

- Next.js обновлён в lockfile с 16.2.3 до 16.3.8, ESLint-конфигурация согласована с 16.3.8. Установлены совместимые исправления зависимостей. Итоговый `npm audit --omit=dev`: **0 известных уязвимостей**.
- Офлайн-обработчик больше не скачивает все шрифты из CSS. Офлайн-страница использует системный шрифт, корректно выбирает русский, английский и иврит. Регистрация отложена на 3 секунды после события загрузки страницы. Версия кеша повышена для замены прежнего содержимого.
- Исправлена отсутствующая цель ссылки «перейти к содержимому» на странице ошибки соединения; в оверлее не создаётся дублирующий ID.
- Текст бегущей строки изменён с белого на существующий коричневый цвет. Расчётный контраст с розовым фоном: **4.52:1**.
- Ссылка Instagram открывается штатным действием ссылки, не ждёт анимации и отложенного `window.open`, который может блокироваться браузером. Декоративная анимация сохранена.
- Удалены неиспользуемые переменная и импорт. Для намеренной прямой загрузки SVG-логотипа и полного перехода к странице записи документированы узкие исключения ESLint.
- Добавлены повторяемые проверки HTTP и офлайн-обработчика.

Исходное пользовательское изменение описания консультации в `treatments.ts` сохранено.

## Что остаётся перед выпуском

1. **Свежий Lighthouse и реальные устройства.** В этом проходе новый Lighthouse не запускался; изменения LCP/TBT численно не подтверждены. Нужен замер нового деплоя без расширений и проверка Safari/iOS и Android с реальными touch-жестами. Chrome viewport не эмулирует все особенности этих устройств.
2. **Домен и SEO.** В проекте нет собственной sitemap/robots и явных canonical в метаданных страниц. Для их корректной настройки нужен основной публичный домен. HTTP alternate-заголовки next-intl не заменяют проверку SEO на финальном домене.
3. **Инструменты разработки.** Полный npm audit сообщает 5 high-позиций одной цепочки `braces → micromatch → fast-glob → @next/eslint-plugin-next → eslint-config-next`. Production audit чистый. Предлагаемый `--force` откатывает конфигурацию на 14.x, поэтому не применён. Не передавать недоверенные glob-шаблоны инструментам сборки; отслеживать исправление upstream.
4. **Предупреждение анимации.** При переключении языка зафиксированы два предупреждения `SplitText called before fonts loaded`. Ошибок JavaScript в просмотренной консоли не обнаружено; синхронизацию декоративного SplitText со шрифтами стоит проверить отдельно на медленном соединении. Главный заголовок не скрывался в ожидании шрифта.
5. Офлайн-поведение проверено изолированным тестом, не отключением реальной сети браузера. Не выполнялись нагрузочные атаки, полный security pentest, юридическая проверка доступности или медицинская экспертиза текстов. Внешние WhatsApp/телефонные обращения не отправлялись.

```sh

npm run lint
node scripts/check-translations.mjs
node scripts/check-offline.mjs
npm audit --omit=dev
npm run start -- --port 3001
# В другом терминале:
python3 scripts/audit-http.py http://localhost:3001
```

HTTP-скрипт возвращает ненулевой код при найденных проблемах. Проверка переводов подтверждает структуру и полноту, а не независимую лингвистическую экспертизу каждого предложения.
