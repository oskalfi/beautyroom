# Safari: проверка 5 октября 2026

Основная проверка: **https://beautyroomky.com/**, Safari 26.6.2 на macOS. Использованы обычное окно и Responsive Design Mode: 390×844 и 1440×900. Это не физический iPhone и не iOS Simulator.

## Подтверждено на опубликованном сайте

- Иврит открывается по умолчанию; главная и логотип отображаются.
- Мобильное меню раскрывает пункты и кнопку записи; переход в Contacts закрывает меню.
- Переключение Contacts на English сохраняет адрес страницы и переводит интерфейс.
- Английская Cosmetics открывается с текстом и ссылками.
- Панель доступности: увеличение текста до 125%, остановка движения, сброс и закрытие работают. Тестовые настройки сброшены.
- Русский главный заголовок при 390×844 имеет требуемые три строки и помещается в окно.
- RTL-стрелка активной процедуры при 390×844 находится справа и смотрит влево. Проверена активация клавиатурным фокусом; имитация ширины не подтверждает автоматическую активацию при touch-прокрутке на iPhone.
- Бегущая строка отображается белым цветом.
- Before/After реагирует на перетаскивание: значение изменилось с 40 до 77.
- Enter на процедуре при телефонной ширине открывает отдельную страницу. Электрокоагуляция показывает ₪ 250+ и 15+ минут.
- Якорь противопоказаний переходит к нужному разделу; текст читается под фиксированной шапкой.
- При 1440×900 криотерапия открывается модально, показывает ₪ 500 и 75+ минут. Escape возвращает к списку процедур, а не к началу страницы.
- Несуществующий `/en/does-not-exist` показывает английскую страницу 404 и ссылку возврата.

## Найдено и исправлено локально

В консоли публичной главной Safari сообщил две ошибки:

```text
Invalid value for <rect> attribute width="calc(100% - 2px)"
Invalid value for <rect> attribute height="calc(100% - 2px)"
```

Источник — декоративная рамка `AddressSection`. Вычисления размеров перенесены из SVG-атрибутов в CSS geometry properties `.borderRect`. Размеры и отступ 1px сохранены, дополнительные JS-измерения не добавлены.

После новой production-сборки локальная главная открыта в том же Safari: консоль пустая, указанные ошибки отсутствуют. `npm run build`, TypeScript, `npm run lint` и `git diff --check` проходят. **Исправление не опубликовано**; публичный сайт следует перепроверить после деплоя.

## Границы проверки

Это функциональная выборочная проверка основных сценариев, не доказательство отсутствия любых ошибок. Не выполнены полный обход каждой процедуры на каждом языке в Safari, VoiceOver-аудит, проверка реального iPhone/iPad, медленной сети, всех жестов, офлайн-режима и всех видео. Внешние сообщения и записи не отправлялись. Измерения Lighthouse этим тестом не заменяются.

Адаптивный режим и инспектор после теста закрыты; Safari возвращён к публичной главной странице.
